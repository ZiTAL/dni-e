# v0.2.1 — headless tooling and a CI-published release

Maintenance release. The shim code is unchanged; this release packages the
headless browser tooling and the handover documentation, and is published by
the tag-driven CI workflow.

## What's new

- **Headless browser tooling**:
  - `scripts/make-firefox-profile.sh` creates an NSS profile with the DNIe
    module loaded, without a display.
  - `tests/test-browser-tls.sh` + Playwright validate the client-certificate
    flow with a software certificate.
- **Documentation**:
  - `docs/09-multiarch-validation.md` — cross-build, musl and QEMU results.
  - `docs/10-headless-browser.md` — what is scriptable and how to handle the
    DNIe PIN.
  - `NEXT-STEPS.md` — post-renewal checklist.
- **CI-published assets**: tarballs for six architectures are now built by the
  release workflow. Debian packages for amd64 and arm64 are built natively in
  CI; the riscv64 package is built on hardware and attached separately.
- **Signed checksums** (`SHA256SUMS.asc`) and public key.

## Install

Debian/Ubuntu:

```bash
sudo apt-get install -y opensc p11-kit pcscd
sudo dpkg -i dnie-pkcs11-compat_0.2.1_arm64.deb
sudo apt-get -f install
```

Tarball:

```bash
sha256sum -c SHA256SUMS --ignore-missing
tar xzf dnie-pkcs11-compat-0.2.1-aarch64.tar.gz
cd dnie-pkcs11-compat-0.2.1-aarch64
sudo ./install.sh --binary --system
```

## Verified

- Debian packages installed on aarch64 and riscv64; token detection with the
  real DNIe on the RISC-V board.
- 21 shim tests on x86-64, aarch64 and riscv64.
- Playwright client-certificate test on x86-64 and aarch64.
- Firefox headless on aarch64 and riscv64.
- CI: release workflow builds six tarballs and two native Debian packages.

## Known limitations

- DNIe certificates expired on 2024-10-18; T7–T9 remain pending renewal.
- The DNIe PIN cannot be typed by Playwright/Selenium; use
  `openssl s_client` with PKCS#11 or Xvfb + VNC (see docs/10).
- The official closed-source DGP/FNMT module is not included or redistributed.
