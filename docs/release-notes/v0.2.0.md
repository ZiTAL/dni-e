# v0.2.0 — Debian packages, unified Autofirma and signed assets

Second release of the DNIe stack for Linux. It adds native Debian packages,
multi-architecture release automation and signed assets.

## What's new

- **Debian packages** for ARM64 and RISC-V 64 (`dnie-pkcs11-compat`), with
  `Provides`/`Conflicts` for the official module names.
- **Unified Autofirma**: the installer now accepts an existing jar and installs
  `autofirma-dnie`, a launcher that works with any Java >= 17. Validated on
  aarch64 (Java 21) and riscv64 (Java 25).
- **Release automation**: a GitHub Actions workflow builds tarballs for
  x86-64, aarch64, riscv64, armv7, ppc64le and s390x, builds Debian packages
  natively, and publishes the release.
- **Signed assets**: `SHA256SUMS` is detached-signed with a project GPG key;
  the public key is attached (`dnie-release-key.asc`).
- Installer synchronization: the prebuilt module mode (`--binary`) used by the
  tarballs, the FNMT alias and browser setup are included everywhere.

## Install

Debian/Ubuntu:

```bash
sudo apt-get install -y opensc p11-kit pcscd
sudo dpkg -i dnie-pkcs11-compat_0.2.0_arm64.deb
sudo apt-get -f install
```

Tarball:

```bash
sha256sum -c SHA256SUMS --ignore-missing
tar xzf dnie-pkcs11-compat-0.2.0-aarch64.tar.gz
cd dnie-pkcs11-compat-0.2.0-aarch64
sudo ./install.sh --binary --system
```

Then:

```bash
./scripts/verify-stack.sh
./scripts/verify-card.sh     # DNIe inserted, chip facing the contacts
```

## Verified

- Debian packages built and installed on **aarch64** (Orange Pi 5) and
  **riscv64** (VisionFive 2), including alias, p11-kit module and token
  detection on the RISC-V board.
- 21 shim tests pass on x86-64, aarch64 and riscv64.
- CI builds and tests on x86-64 and ARM64.
- Checksums verified after downloading the published assets.

## Known limitations

- DNIe certificates expired on 2024-10-18; real TLS authentication and signing
  (T7–T9) remain pending renewal, which is in person.
- Autofirma is not bundled; pass `--autofirma-jar`.
- The official closed-source DGP/FNMT module is not included or redistributed.
- RISC-V Debian packages are built on hardware, not in CI (GitHub does not
  provide RISC-V runners); tarballs for other architectures are cross-built.
