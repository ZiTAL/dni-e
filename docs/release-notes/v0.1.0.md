# v0.1.0 — DNIe stack for aarch64 and riscv64

First public release of the multi-architecture DNIe stack for Linux.

It provides the PKCS#11 module that Spanish DNIe applications and guides expect
(`libpkcs11-dnie.so`) on top of **OpenSC**, plus the tooling to install it on
FHS distributions and non-FHS systems, configure browsers, and sign documents
with Autofirma.

## Assets

| Architecture | Asset |
|---|---|
| ARM64 | `dnie-pkcs11-compat-0.1.0-aarch64.tar.gz` |
| RISC-V 64 | `dnie-pkcs11-compat-0.1.0-riscv64.tar.gz` |
| x86-64 (bonus) | `dnie-pkcs11-compat-0.1.0-x86_64.tar.gz` |
| Checksums | `SHA256SUMS` |
| Instructions | `INSTALL.md` |

Each tarball contains:

- the prebuilt `prebuilt/libpkcs11-dnie.so` for that architecture;
- the full source and `Makefile`;
- `install.sh` (with `--binary` mode);
- documentation and the polish/browser scripts.

## Install

```bash
# Download the asset for uname -m, then:
sha256sum -c SHA256SUMS --ignore-missing
tar xzf dnie-pkcs11-compat-0.1.0-aarch64.tar.gz
cd dnie-pkcs11-compat-0.1.0-aarch64
sudo ./install.sh --binary --system
```

The installer:

1. installs `pcsc-lite`, `ccid`, `opensc` and `p11-kit` if needed;
2. installs the prebuilt module and the `libpkcs11-fnmtdnie.so` alias;
3. registers it with p11-kit;
4. enables `pcscd` and configures polkit/`plugdev` for headless access;
5. adds the module to Firefox profiles and Chrome/Chromium (with backups).

Then:

```bash
./scripts/verify-stack.sh
./scripts/verify-card.sh     # DNIe inserted, chip facing the contacts
```

## Verified

- Reader, ATR, OpenSC identification and certificate listing on:
  - **aarch64** (Orange Pi 5, Debian 13),
  - **riscv64** (VisionFive 2, Debian 13).
- PKCS#11 objects and NSS/Firefox certificate listing through the shim on both.
- 21 shim tests (resolution, security, portability) on x86-64, aarch64 and
  riscv64.
- Autofirma XAdES, PAdES and PKCS#11 signing on both architectures
  (laboratory stores).
- CI build and tests on x86-64 and ARM64.

## Known limitations

- The DNIe certificates used during validation expired on 2024-10-18, so real
  authentication and signing (TLS/PIN) could not be tested end to end. Renewal
  is in person.
- Autofirma needs a JRE >= 17 and is not bundled; pass `--autofirma-jar`.
- The official closed-source DGP/FNMT module is not included or redistributed.
- Chromium on riscv64 is not a supported target; Firefox is the reference.
